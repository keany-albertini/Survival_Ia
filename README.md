# Survival_Ia

Prototype mobile de jeu de survie inspiré du projet **Everwild**.

## Première version
- Vue du dessus jouable sur téléphone
- HUD compact et discret
- Direction artistique réaliste stylisée
- Vie, faim et soif
- Récolte de bois, pierre, baies et cristaux
- Ressources rares plus colorées
- Inventaire simple
- Créatures hostiles
- Combat de base
- Commandes tactiles

## Contrôles
- **Téléphone** : joystick à gauche, boutons Récolter / Attaque / Manger à droite
- **PC** : ZQSD/WASD ou flèches, E pour récolter, Espace pour attaquer

Le prototype principal est dans `index.html`.
